# T±ck

A tiny, fast, mobile-first tap counter. Plain HTML, CSS and a small vanilla JS file. No build step, no dependencies, no backend.

## Project structure

```
counter-app/
├── index.html   # markup
├── style.css    # styles
├── app.js       # counter logic, persistence, celebration
├── favicon.svg  # app logo / browser tab icon
└── README.md
```

## Run locally

Open `index.html` in a browser.
